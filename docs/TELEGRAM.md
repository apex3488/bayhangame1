# BAYHAN GAME в Telegram: бот, Mini App, единый аккаунт

Один игрок — один аккаунт — одна экономика: браузер, Mini App и бот работают с одной базой Supabase и одними SQL-функциями.

## Архитектура

```
Браузер  https://bayhangame1.vercel.app ──────────────┐  сессия Supabase (JWT игрока)
Mini App  тот же сайт, вход через /tg ────────────────┤  → RPC игры (auth.uid())
                       │ initData (подпись Telegram)   │
                       ▼                               ▼
        Edge Function telegram-auth ──────────► Supabase Postgres (единственный источник истины)
Telegram ─webhook─► Edge Function telegram-bot ─► tg_call() → те же RPC от имени привязанного игрока
```

| Часть | Где | Файлы |
|---|---|---|
| Игра и Mini App | Vercel (`main` → автодеплой) | `app/tg/page.tsx`, `components/telegram-bridge.tsx`, `components/telegram-card.tsx`, `lib/telegram.ts` |
| Вход через Telegram | Supabase Edge Function `telegram-auth` | `supabase/functions/telegram-auth/index.ts` |
| Бот | Supabase Edge Function `telegram-bot` (webhook) | `supabase/functions/telegram-bot/index.ts` |
| Общий код функций | — | `supabase/functions/_shared/telegram.ts` |
| База | Supabase | `supabase/migrations/0023_telegram.sql`, `0024_telegram_link_code_fix.sql` |

### Вход в Mini App

1. Telegram открывает `https://bayhangame1.vercel.app/tg` и передаёт подписанный `initData`.
   SDK `telegram-web-app.js` загружается **только** внутри Telegram; обычный браузер его не грузит.
2. `/tg` отправляет `initData` в `telegram-auth`. Функция проверяет подпись по официальному алгоритму
   (HMAC-SHA256, ключ `HMAC_SHA256("WebAppData", bot_token)`, все поля кроме `hash`, отсортированы),
   возраст `auth_date` (не старше 1 часа), формат `user.id`. Токен бота хранится в Supabase Vault и в браузер не попадает.
3. Telegram id привязан → функция выдаёт одноразовый токен (`generateLink`), клиент меняет его на обычную сессию
   Supabase (`verifyOtp`). Дальше Mini App — это обычная игра с обычной сессией: все проверки делают те же RPC.
4. Не привязан → экран выбора: «Я новый игрок» (имя → аккаунт) или «У меня уже есть аккаунт»
   (вход логином и паролем → привязка). Привязка требует доказать **обе** стороны: подпись Telegram и сессию игрока.

Если в Mini App сохранилась сессия другого игрока, она заменяется аккаунтом этого Telegram-пользователя.

### Привязка браузерного аккаунта

- Из браузера: Профиль → Telegram → «Привязать Telegram» → кнопка открывает `t.me/BayhanGame2_bot?start=link_<код>`.
  Код из 10 символов (~50 бит), одноразовый, живёт 10 минут, не больше 10 в час.
- Из Mini App: «У меня уже есть аккаунт» → логин и пароль.
- Автоматического слияния по имени или username **нет**. Один Telegram — максимум один аккаунт и наоборот (уникальные ключи).
- Аккаунт, созданный в Telegram, получает логин `tg<telegram_id>`. Пароль для браузера задаётся в Профиле.

### Бот

Кнопки: 🎮 Играть (Mini App), 👤 Профиль, 💰 Баланс, 🎁 Ежедневная награда, 🏆 Рейтинг, 📋 Задания, 👥 Пригласить друга, ℹ️ Помощь.
Команды: `/start /play /profile /balance /daily /top /tasks /invite /help`, скрытая `/admin` (только у ролей из `admin_roles`;
остальным отвечает как на неизвестную команду). Кнопка меню чата открывает Mini App.

- `/start` для нового человека **не** создаёт аккаунт молча: предлагает «Создать аккаунт» или «У меня уже есть аккаунт».
  `/start ref_<код>` передаёт реферальный код в регистрацию, `/start link_<код>` привязывает браузерный аккаунт.
- Повторный `/start`, двойное нажатие «Создать», перезапуск функции — дубликатов нет: логин `tg<id>` уникален в базе.
- Защита webhook: секретный заголовок `X-Telegram-Bot-Api-Secret-Token` (из Vault), повторно доставленный `update_id`
  обрабатывается один раз, лимит 30 действий в минуту на пользователя, только личные чаты.

### Синхронизация

Сервер — единственный источник истины, клиенты ничего не хранят у себя.

| Действие | Как другие интерфейсы видят изменение |
|---|---|
| Любая операция в браузере или Mini App | RPC пишет в базу в одной транзакции; бот читает ту же базу при следующем сообщении |
| Действие в боте (ежедневная награда) | та же `claim_daily`; игра перечитывает состояние при открытии и при каждом возврате в окно (`visibilitychange`/`focus`) |
| Одновременная игра в двух местах | функции игры блокируют строку игрока (`for update`), проверяют средства и пишут журнал атомарно; ключи идемпотентности не дают повторить начисление |

WebSocket не добавлен: перечитывания при возврате достаточно, лишняя инфраструктура не нужна.

### Безопасность

- Служебные функции `tg_*` доступны только `service_role` (Edge Functions). Игрок не может вызвать `tg_call` от чужого имени,
  прочитать токен (`tg_config`) или привязать чужой аккаунт — это проверяют тесты.
- Клиент не передаёт ни user id, ни баланс, ни цену: личность берётся из подписи Telegram или из JWT Supabase, цены — из базы.
- Лимиты: вход через Telegram — 20 запросов в минуту на пользователя, бот — 30.
- В логи не пишутся токены, `initData` и тела запросов.

## Бот в группах: вся игра в чате

Бота можно добавить в любую группу и играть прямо в ней. Команды пишутся по-русски, можно без «/»; сумма — `1000`, `5к`,
`2.5кк`, `3млрд`, `все`. Полный список — «помощь». Все действия выполняют те же SQL-функции, что и сайт, от имени игрока.

| Раздел | Команды |
|---|---|
| Аккаунт | «б»/«баланс», «профиль», «бонус», «топ», «топ чата», «ник Имя», «история», «вип», «события» |
| Работа | «работа» (список с перерывами), «работа курьер» |
| Банк | «банк», «положить 10к», «снять все», «вклад 100к 30», «вклады» (созревшие выплачиваются), «btc», «купить btc 10к», «продать btc все» |
| Переводы | «перевод 1к» ответом на сообщение, «перевод Ник 1к» (комиссия — из настроек экономики) |
| Имущество | «магазин», «машины», «недвижимость», «бизнесы», «роскошь», «купить Частный остров», «продать …», «улучшить …», «нанять …», «собрать», «имущество» |
| Добыча, кейсы | «добыча», «ресурсы», «купить дерево 10», «продать дерево все», «кейсы», «кейс Золотой», «промо КОД» |
| Задания | «задания», «достижения», «забрать» (все готовые награды) |
| Социальное | «пригласить», «корпа», «корпа создать Имя», «корпа вложить 10к», «корпа пригласить» (ответом), «топ корп», «брак» (ответом), «развод» |
| Игры на ставки | «казино 1к», «спин 1к», «слоты 1к», «кубик 1к 6», «баскетбол/дартс/боулинг 1к», «вверх 1к»/«вниз 1к», «трейд вверх 1к», «краш 1к 2» (ракета с живым множителем и кнопкой «Забрать»), «мины 1к 3» (поле 5×5 кнопками) |
| PvP | «дуэль 1к» ответом на сообщение (вызов) или без ответа (для любого); ставки списываются атомарно, победитель 50/50 |
| Мини-игры | «мафия» (4–12), «шпион» (3–10), «крокодил»; «стоп игра» — создатель или админ чата |
| Чат | «настройки» — админ чата включает/выключает ставки и мини-игры; «топ чата» — рейтинг участников этого чата |

Бот не реагирует на обычную переписку: слово-команда с лишними словами («я сегодня устал») считается разговором.

**Мини-игры без лички.** Роли Мафии, локация Шпиона и слово Крокодила показываются всплывающим окном по кнопке —
его видит только нажавший. Ночью в Мафии кнопку жмут все живые игроки (мирные — «подозреваемый»), поэтому по нажатиям
нельзя понять, кто есть кто. Фазы двигаются, когда все сделали ход, или по таймеру: `pg_cron` раз в 10 с вызывает бота,
но только если у какой-то игры истекло время. Состояние игры хранится в `tg_party_games` с проверкой версии, поэтому
одновременные нажатия не теряются. Победителям с аккаунтом начисляется `party_reward` ($10,000), не больше
`party_rewards_per_day` (5) раз в сутки; в Крокодиле — только если в игре было от 3 человек. Оба значения меняются в
админке (раздел «Экономика»).

**Админ-панель в боте** (только в личке, только у ролей из `admin_roles`): `/admin` — меню со статистикой, играми и
промокодами; «игрок Ник» — карточка с кнопками блокировки; «выдать/отнять Ник 10к причина»; «бан Ник причина»,
«разбан Ник»; «вип Ник 2 30»; «промо создать КОД 50к 100»; «игра выкл slots»; «рассылка текст» — уведомление в игре и
сообщение всем игрокам с привязанным Telegram. Каждая команда вызывает ту же `admin_*` функцию, что и веб-админка:
роль проверяет сервер, действие пишется в журнал аудита. Для остальных игроков этих команд не существует.

**Чтобы бот видел команды без «/» в группах**, ему нужно читать сообщения чата. Два способа:
сделать бота администратором группы (права не нужны) — или один раз в BotFather: `/mybots → BayhanGame2_bot →
Bot Settings → Group Privacy → Turn off` (действует для групп, куда бота добавят после этого). Команды с «/» и кнопки
работают в любом случае. Крокодилу нужен этот режим обязательно: догадки — обычные сообщения.

Код: `supabase/functions/telegram-bot/` (`index.ts` — маршрутизация, `economy.ts`, `games.ts`, `party-io.ts`, `admin.ts`,
`ctx.ts`), чистая логика без сети — `supabase/functions/_shared/bot-commands.ts` и `party.ts`, названия предметов —
`_shared/names.ts` (генерируется `npm run bot:names` из словарей игры). Миграции `0025`–`0029`.

### v5: скорость, админка, лотерея, раздачи (миграция 0028)

- **Скорость.** Функция закреплена за регионом базы: вебхук `…/telegram-bot?forceFunctionRegion=ap-southeast-1`
  (без этого запрос шёл через Европу, ~3 с на ответ). Каждый апдейт — один вызов `tg_begin` (дедупликация, лимит,
  настройки чата, привязка, игра, шаг мастера админки); первый ответ уходит прямо в ответе вебхука, ставки — одним
  `tg_rpc_cash`. Замер: `node scripts/tg-latency.mjs`.
- **Меню кнопками:** «меню» — все разделы одним нажатием.
- **Лотерея чата:** «лотерея 1к» — ставка, шанс пропорционален ставке, розыгрыш через 5 минут, комиссия 5% сгорает;
  если участник один — возврат.
- **Раздачи:** «раздача 10к 5» — сумма поровну первым N нажавшим, через 30 минут остаток возвращается автору.
- **Админка в личке** (`админ`): дашборд и статистика за 7 дней, поиск и карточка игрока (выдать/отнять, банк, BTC,
  бан, VIP, журнал операций, аудит, сообщение, сброс медиа, роль), экономика, игры и лимиты, работы, промокоды,
  события, VIP, рассылка, новости, чаты бота, аудит, крупные переводы, роли. Ввод значений — пошаговые мастера с
  подтверждением, каждое изменение пишется в аудит.

## Модерация групп (только владелец, миграция 0029)

Отдельная от игровой админки система: меняет только права в Telegram-группе. Игровые аккаунты,
балансы, рейтинги и игровые баны она не трогает (это проверяет тест `separation`). Код:
`supabase/functions/_shared/moderation.ts` (разбор команд, права, вызовы Telegram — без базы),
`supabase/functions/telegram-bot/mod.ts` (команды, панель, массовые операции), таблицы `tg_mod_*`.

**Кто может.** Только владелец BAYHAN GAME: роль `owner` в `admin_roles` и привязанный Telegram.
Проверка по настоящему Telegram ID отправителя (не по нику), на сервере, на каждую команду и
каждое нажатие кнопки. Быть админом группы самому не нужно: согласие группы — это права, которые
её владелец выдал боту. Бот делает только то, на что ему дали право (блокировка, удаление). Сообщения анонимных админов и от имени
каналов не принимаются. Админы группы, её создатель, владелец игры и сам бот защищены.

### Команды в группе (ответом на сообщение нарушителя)

| Команда | Что делает |
|---|---|
| `бан`, `бан 1ч`, `бан 7д Реклама` | бан навсегда или на срок, с причиной |
| `разбан` (или `разбан 123456789`) | снять бан |
| `мут`, `мут 30м`, `мут 1д Оскорбления`, `мут навсегда` | запрет писать (по умолчанию — из настроек, 1 ч) |
| `размут` | вернуть права (как у группы, при закрытом чате — сохранённые) |
| `кик` | удалить из группы, вернуться можно |
| `дел` | удалить сообщение |
| `варн причина`, `варны`, `снятьварн` | предупреждения; после 3-го бот пишет владельцу, сам не наказывает |
| `закрыть чат`, `открыть чат` | писать могут только админы / вернуть прежние права |
| `очистить 50` | удалить до N (1–500) последних сообщений; больше 50 — с подтверждением |
| `удалить все сообщения` (`очистить всё`, `очистить чат`) | удалить все сообщения, которые бот видел за 48 ч (до 20 000 за раз), всегда с подтверждением |
| `слоумод` | показать медленный режим (менять его ботам Telegram не даёт) |
| `модерация` | панель (в личке бота) |

Сроки: `30с`, `5м`, `1ч`, `1д`, `2н` — от 30 секунд до 366 дней (короче или длиннее Telegram
считает бессрочным, поэтому такие сроки отклоняются, а не превращаются в «навсегда»).

По умолчанию работает **тихо**: команда владельца и сообщение нарушителя удаляются, в чат ничего
не пишется. Ошибки — коротким сообщением, которое удаляется само. Всё пишется в `tg_mod_actions`.

### Панель `модерация` (в личке бота)

Выбор группы → права бота и ваши, состояние чата → 🔨 Наказания (снять), 👥 Участники, 🧹 Очистка,
🔒 Закрыть/открыть чат, ⏱ Медленный режим, ⚠️ Предупреждения, 📊 Статистика, 📜 История,
👥 Массовые действия, 🚫 Всем бан, ⚙️ Настройки (тихий режим, удаление сообщения нарушителя, мут по
умолчанию, время уведомлений).

**Массовые действия и «Всем бан».** Цели: активные за 24 ч / 7 дней, все известные, или список ID.
Предпросмотр (группа, число, первые имена) → «Продолжить» → ввод точной фразы с ID группы
(`ВСЕМ БАН -100…`). Выполняется таймером pg_cron пачками с учётом лимитов Telegram, кнопка
⏹ Остановить. «↩️ Отменить» разбанивает только тех, кого заблокировала эта операция; кто был в бане
раньше, остаётся в бане. Каждый результат — в `tg_mod_bulk_targets` и `tg_mod_actions`.

### Настройка

1. Владелец группы добавляет бота и назначает его администратором с правами **Блокировка
   пользователей** и **Удаление сообщений**. Вам самим быть админом этой группы не нужно. Права «Изменение профиля» и прочие не нужны.
2. Бот должен видеть обычные сообщения (`бан`, `мут 1ч` без «/»). Администраторы получают все
   сообщения и так; если бот не админ — в @BotFather → Bot Settings → Group Privacy → Turn off.
3. Вебхук получает `chat_member` (вход и выход участников): `node scripts/telegram-setup.mjs`.
4. Проверка: в личке бота «модерация» → группа: в строке «Бот» должны быть ✅.
5. Тест: в тестовой группе со вторым аккаунтом — `мут 1м`, `размут`, `варн`, `дел`.

### Ограничения Telegram

- Полного списка участников ботам Telegram не даёт: бот знает тех, кто писал, входил или выходил
  при нём. «Всем бан» банит только их и так и пишет.
- Удалять можно только сообщения младше 48 часов и только те, что бот видел (ID хранятся 48 ч).
  `deleteMessages` не сообщает, какие сообщения уже были удалены, поэтому пишется «удалено до N».
- Медленный режим ботам не изменить — только прочитать.
- Анонимных админов и посты от имени каналов наказать по ответу нельзя: автор неизвестен.

## Резервная копия и восстановление

`npm run db:backup` сохраняет все таблицы `public` и нужные поля `auth.users` в `backups/<время>/*.json` (папка в `.gitignore`:
там хэши паролей). Копия перед миграцией 0023 — `backups/2026-10-28T08-57-26-016Z`.

Восстановление строк из копии — через `psql`/скрипт `insert … on conflict do nothing` по таблицам в порядке зависимостей
(`auth.users` → `profiles` → `wallets` → остальные), при отключённом триггере `ledger_entries_immutable` и только после
согласования. Откат миграции 0023 описан в её шапке (удаляет лишь новые таблицы и функции, игровые данные не трогает).

## Что осталось сделать вам

1. Открыть @BayhanGame2_bot в Telegram на телефоне: `/start` → «Играть», проверить вход, полноэкранный режим и кнопку «Назад».
2. Проверка одного аккаунта: в браузере Профиль → Telegram → «Привязать» → бот → в боте «💰 Баланс» = баланс в игре;
   заберите награду в боте → в браузере вернитесь на вкладку — баланс обновится, повторно забрать нельзя.
3. По желанию: BotFather → Configure Mini App (см. выше) и аватар бота.
4. Для игры в группах: BotFather → Group Privacy → Turn off (или сделайте бота админом в чате), добавьте бота в группу
   и попробуйте «бонус», «казино 1к», «мины 1к 3», «мафия» с друзьями.
5. Токен бота был отправлен в чат: если этот чат могли видеть другие, перевыпустите токен (раздел «Смена токена»).
