# BAYHAN GAME 2.0

Новая браузерная игра. Старый Telegram-проект не используется как основа: только как источник функций.

- Статус и следующие шаги: [docs/STATUS.md](docs/STATUS.md)
- Реестр функций старого проекта: [docs/FUNCTIONALITY_REGISTRY.md](docs/FUNCTIONALITY_REGISTRY.md)
- База данных: Supabase. Миграции в `supabase/migrations/`, проверки в `supabase/tests/`.

Переменные окружения — в `.env.example`. Реальные значения хранятся в `.env.local` и в git не попадают.
